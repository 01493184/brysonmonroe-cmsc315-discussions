# Unit 2 Discussion: Stacks and Queues

## Overview

This assignment explores two fundamental linear data structures:

- Stack (LIFO)
- Queue (FIFO)

## Learning Objectives

- Implement stack operations
- Implement queue operations
- Understand LIFO and FIFO behavior
- Create edge cases

1. What concepts or skills did you learn while completing this assignment?
   My approach for this particular assignment was to use a queue to make data appear in the order that it comes to me. The first item added to the queue is processed first. This structure is demonstrated by using numbers, where they were handled in the order they showed up in. This shows how a queue can be useful for managing numerical data in an organized way.
   
2. What challenges did you encounter, and how did you overcome them?
One challenge I encountered was separating the difference between a stack and a queue and knowing how each one will effect the program. I overcame this by thinking about particular examples that would include a stack and queue implementation, such as a customer lines for FIFO and a school bus picking up children for LIFO. This really helped me understand how LIFO and FIFO work and apply them correctly in the program.

3. Explain the differences between stacks and queues as this relates to real-world applications.
   A stack uses LIFO because the most recently added item is the first item that can be removed. A real-world example is when a school bus is picking up kids, where the last kid that gets picked up is usually the first kid to get dropped off after school. A queue uses FIFO because the first item added is the first item removed. A real-world example is a line at a checkout, where the person who arrives first is usually going to be served first.
