# Unit 3 Discussion: List Operations

## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Requirements

1. Test insertion at the beginning, middle, and end.
2. Test deletion at the beginning, middle, and end.
3. Search for existing and missing values.
4. Demonstrate edge cases.
5. Create a real-world scenario.

1. What concepts or skills did you learn while completing this assignment?
Working through this assignment really helped me learn how to work with lists and utilize list operations such as adding, removing, updating, and obtaining elements. 2. What challenges did you encounter, and how did you overcome them?
One challenge I discovered was getting a good idea how different list operations affect the elements and their positions inside of the list. If you take a quick glance, the concept itself was easy to get misinterpreted with the idea of indexing or mistakenly not knowing that the index begins at zero. I overcame these challenges by reviewing examples, testing my code with smaller lists, and looking at the output after each operation was used. This helped me tremendously identify mistakes and understanding why they occurred.
   
3. How do list operations impact performance in real-world applications?
List operations can have a significant impact in the real-world, typically when applications work with large amounts of data. Operations like getting an element by its index are generally pretty quick, while inserting or removing elements from certain positions can call for shifting of other elements and take more time to get done. For example, you're trying to register for classes or you go to urgent care and your info needs to be collected in order to proceed in the next steps. Understanding these performance differences helps developers go in the right direction in data structures and write more efficient code.
